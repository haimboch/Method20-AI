# METHOD 20 AI

מערכת מחקר טכני יומית, LONG בלבד, ללא פקודות מסחר, ללא backtesting.

## הפיילוט: חמש מניות
SPCX, WDC, NBIS, IREN, MU. מדדים: SMA20 בלבד, CCI(14), נפח מסחר, נרות יפניים.
מקור נתוני OHLCV: **Massive API** עם מפתח סודי בשם `MASSIVE_API_KEY` ב־GitHub Settings → Secrets and variables → Actions. אין לשמור את המפתח בקוד. מסלול הנתונים עשוי להגביל טווח היסטוריה וקצב בקשות.

## הרצה בענן ללא התקנת Python
1. פתח את לשונית Actions במאגר.
2. בחר **METHOD 20 Manual Report**.
3. לחץ **Run workflow** ובחר main.
4. המתן לסיום הריצה; בתחתית עמוד הריצה הורד את ה-Artifact בשם `method20-html-report`.
5. חלץ את קובץ ZIP ופתח `report.html` לצד תיקיית `charts`. מופיע גם `results.json`.

**קיימת גם הרצה אוטומטית בתום יום מסחר**. בגרסת 0.7 הדוח מציג צ׳קליסט מתמטי לכל מניה, ויכול להפעיל AI חזותי אם הוגדר GitHub Secret בשם `OPENAI_API_KEY` (מפתח OpenAI Platform נפרד מהמנוי ל-ChatGPT). ללא המפתח יופיע `NOT_CONFIGURED`, והדוח עדיין יפעל כרגיל. השירות עשוי לחייב על שימוש API; מפתח OpenAI לא נדרש להרצת חישובים או גרפים. עדיין לא הוגדרו הרצה ב-23:30 או משלוח ב-06:00.
הזיהוי הנוכחי היוריסטי וראשוני; אין להסיק ממנו אות מסחר מאומת.
אם ספק הנתונים נכשל, הסמל יוצג בדוח עם הודעת שגיאה במקום נתונים מומצאים.

## v0.9 | GitHub Actions אוטומטי

- שתי משבצות cron (20:40 ו-21:40 UTC בימים שני עד שישי) מכסות את שעוני החורף/קיץ של ישראל. `schedule_guard.py` מאשר הרצה רק בשעה 23:30–00:29 בישראל, לאחר סגירת NYSE; זמן ההפעלה המתוכנן בפועל הוא **23:40**, משום ש-GitHub Actions אינו מבטיח התחלה מדויקת.
- אם NYSE סגורה (חג או סוף שבוע) ההרצה מדולגת. בזמן הרצה מתוזמנת נבדק שנר המחיר האחרון של כל מניה הוא מתאריך המסחר בארה״ב; נר ישן גורם לכישלון מסומן.
- בכל ריצה מוצלחת שמור `method20-html-report` ב-Artifacts ל-30 ימים. הדוח **אינו נשלח למייל בשעה 06:00** עדיין; זו משימת השלב הבא.
- ניתן להפעיל תמיד באופן ידני דרך Run workflow גם בחגים ובסופי שבוע; בהרצה ידנית לא נדרש שתאריך הנר האחרון יהיה היום.
- **מגבלה:** GitHub Actions עשוי להתעכב או להחמיץ הרצות schedule. יש לבדוק בתחילת הדרך כמה הרצות, ובהמשך להוסיף ניטור/התראה. יש גם עלות שימוש ב-API לניתוח תמונות.
- כדי לכבות את התזמון: השבת את workflow ב-Actions או הסר את טריגר ה-`schedule`.
