# METHOD 20 AI

מערכת מחקר טכני יומית, LONG בלבד, ללא פקודות מסחר, ללא backtesting.

## רשימת מעקב רחבה: 35 ניירות
רשימת המעקב נמצאת ב־`watchlist.txt` וניתן לשנות אותה בכל חודש. כוללת SPCK, WDC, NBIS, IREN, MU ועוד 30 סימולים. קרן The SPAC and New Issue ETF החליפה סימול מ־SPCX ל־SPCK באפריל 2026; לכן עודכן הסימול כדי למנוע שיוך שגוי. הרשימה הנוכחית היא נקודת פתיחה בלבד, אינה המלצת קנייה, ואינה מבטיחה התאמה לכללי הסריקה או זמינות נתונים מלאה. מדדים: SMA20 בלבד, CCI(14), נפח מסחר, נרות יפניים.
מקור נתוני OHLCV: **Massive API** עם מפתח סודי בשם `MASSIVE_API_KEY` ב־GitHub Settings → Secrets and variables → Actions. אין לשמור את המפתח בקוד. מסלול הנתונים עשוי להגביל טווח היסטוריה וקצב בקשות.

## הרצה בענן ללא התקנת Python
1. פתח את לשונית Actions במאגר.
2. בחר **METHOD 20 EOD Report**.
3. לחץ **Run workflow** ובחר main.
4. המתן לסיום הריצה; בתחתית עמוד הריצה הורד את ה-Artifact בשם `method20-html-report`.
5. חלץ את קובץ ZIP ופתח `report.html` לצד תיקיית `charts`. מופיע גם `results.json`.

**קיימת גם הרצה אוטומטית בתום יום מסחר**. בגרסת 0.7 הדוח מציג צ׳קליסט מתמטי לכל מניה, ויכול להפעיל AI חזותי אם הוגדר GitHub Secret בשם `OPENAI_API_KEY` (מפתח OpenAI Platform נפרד מהמנוי ל-ChatGPT). ללא המפתח יופיע `NOT_CONFIGURED`, והדוח עדיין יפעל כרגיל. השירות עשוי לחייב על שימוש API; מפתח OpenAI לא נדרש להרצת חישובים או גרפים. ההרצות והשליחה המתוזמנות כבר הוגדרו, אך ההפעלה בפועל אינה מובטחת לשעה מדויקת.
הזיהוי הנוכחי היוריסטי וראשוני; אין להסיק ממנו אות מסחר מאומת.
אם ספק הנתונים נכשל, הסמל יוצג בדוח עם הודעת שגיאה במקום נתונים מומצאים.
