# METHOD 20 AI

מערכת מחקר טכני יומית, LONG בלבד, ללא פקודות מסחר, ללא backtesting.

## רשימת מעקב רחבה: 35 ניירות
רשימת המעקב נמצאת ב־`watchlist.txt` וניתן לשנות אותה בכל חודש. כוללת SPCK, WDC, NBIS, IREN, MU ועוד 30 סימולים. קרן The SPAC and New Issue ETF החליפה סימול מ־SPCX ל־SPCK באפריל 2026; לכן עודכן הסימול כדי למנוע שיוך שגוי. הרשימה הנוכחית היא נקודת פתיחה בלבד, אינה המלצת קנייה, ואינה מבטיחה התאמה לכללי הסריקה או זמינות נתונים מלאה. מדדים: SMA20 בלבד, CCI(14), נפח מסחר, נרות יפניים.
מקור נתוני OHLCV: **Massive API** עם מפתח סודי בשם `MASSIVE_API_KEY` ב־GitHub Settings → Secrets and variables → Actions. אין לשמור את המפתח בקוד. מסלול הנתונים עשוי להגביל טווח היסטוריה וקצב בקשות.

## הרצה בענן ללא התקנת Python
1. פתח את לשונית Actions במאגר.
2. בחר **METHOD 20 Manual Report**.
3. לחץ **Run workflow** ובחר main.
4. המתן לסיום הריצה; בתחתית עמוד הריצה הורד את ה-Artifact בשם `method20-html-report`.
5. חלץ את קובץ ZIP ופתח `report.html` לצד תיקיית `charts`. מופיע גם `results.json`.

**קיימת גם הרצה אוטומטית בתום יום מסחר**. בגרסת 0.7 הדוח מציג צ׳קליסט מתמטי לכל מניה, ויכול להפעיל AI חזותי אם הוגדר GitHub Secret בשם `OPENAI_API_KEY` (מפתח OpenAI Platform נפרד מהמנוי ל-ChatGPT). ללא המפתח יופיע `NOT_CONFIGURED`, והדוח עדיין יפעל כרגיל. השירות עשוי לחייב על שימוש API; מפתח OpenAI לא נדרש להרצת חישובים או גרפים. עדיין לא הוגדרו הרצה ב-23:30 או משלוח ב-06:00.
הזיהוי הנוכחי היוריסטי וראשוני; אין להסיק ממנו אות מסחר מאומת.
אם ספק הנתונים נכשל, הסמל יוצג בדוח עם הודעת שגיאה במקום נתונים מומצאים.

### הפעלה נדרשת (חד-פעמית)
1. הפעל אימות דו-שלבי בחשבון Google של השולח.
2. צור **Google App Password** בחשבון Google (אם האפשרות זמינה בחשבונך). אין להשתמש בסיסמת Gmail הרגילה.
3. ב-GitHub, Settings → Secrets and variables → Actions → New repository secret, צור `GMAIL_APP_PASSWORD` והדבק את סיסמת האפליקציה. לעולם אל תכניס אותה לקוד או להודעות בצ'אט.
4. הפעל את דוח הלילה פעם אחת עם הגרסה החדשה כדי שיופיע `metadata.json` בארטיפקט. לאחר מכן ניתן להפעיל ידנית `METHOD 20 Morning Email` כדי לבדוק שליחה; הבדיקה ידנית תשלח דוא״ל אמיתי אם יש דוח תואם מהיממה-יומיים האחרונים.

**חשוב:** עד להגדרת `GMAIL_APP_PASSWORD` הדוא״ל לא יישלח והרצה זכאית תיכשל עם שגיאה גלויה. הודעת מייל יכולה להכיל רק ZIP עד כ-18MB; בהרחבת רשימת המניות ל־40 ייתכן שנצטרך לשלוח קישור להורדה במקום קובץ מצורף. ההרצה עשויה להתעכב או לא להתבצע בדיוק ב־06:10 בשל מגבלות GitHub cron. הרצה חוזרת ידנית של workflow השליחה עלולה לשלוח כפילות. התזמון אינו ערוץ התראה מובטח; מומלץ לבקר את ההרצות הראשונות.
